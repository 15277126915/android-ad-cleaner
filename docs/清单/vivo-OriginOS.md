# vivo / OriginOS 手动清单

路径实测机型：vivo X300 Ultra（V2547DA，OriginOS 6，Android 16），2026-10-22。iQOO 结构相近。当前源码新增机型脚本 `recipes/vivo-V2547DA/`，整段自动执行仍待真机验证；V2547A 也会匹配它，版本不同时走安全模式，不代表 OriginOS 7 已适配。发布与验证范围见[更新记录](../../CHANGELOG.md)。
符号：🔴 关掉　🟢 保留　⚠️ 注意

---

## 1. 系统：广告与隐私

**路径**：设置 → 安全 → 更多安全设置 → 广告与隐私

- 🔴 个性化广告、个性化推荐、智能推荐服务

## 2. 负一屏

**路径**：桌面从左边缘向右滑 → 右上齿轮 → 更多设置 → 个性化推荐

- 🔴 服务推荐、资讯推荐
- 🔴 内容精选、热点资讯
- 🟢 小V建议（航班、快递提醒）
- ⚠️ 便捷生活 → 推荐服务不要关：那 10 个图标（扫码、手电筒、计算器等）都靠它补位，关了整块变空。

## 3. 全局搜索

**路径**：设置 → 系统管理与升级 → 全局搜索

- 🔴 首页展示内容 → 搜索框推荐词、推荐卡片
- 🔴 推荐热搜榜单 → 热门搜索
- 🔴 个性化内容 → 广告个性化
- 🟢 历史记录、应用建议、搜索结果个性化

## 4. 应用商店

**路径**：应用商店 → 我的 → 设置

- 🔴 关于 → 个性化推荐
- 🔴 服务管理 → 签到有礼、顶部轮播图、顶部栏目、开屏、摇一摇、悬浮窗、限时推广
- 🟢 我的服务、空间清理
- ⚠️ 开屏引导页「开启消息推送接收活动」取消勾选。

## 5. 浏览器

**路径**：浏览器 → 我的 → 齿轮

- 🔴 首页设置 → 极简首页；首页上滑展示资讯
- 🔴 隐私权限设置 → 个性化内容、第三方应用来源个性化推荐
- 🔴 网页浏览设置 → 网页下载相关推荐
- 🔴 更多设置 → WiFi 连接跳转新闻资讯
- ⚠️ 浏览器页面常跳到资讯、小说、领金币弹窗，一步一看。

## 6. 阅图锁屏

**路径**：设置 → 桌面、锁屏与壁纸 → 锁屏设置 → 阅图锁屏

- 🔴 阅图锁屏（关「锁屏横滑进入阅图」时总开关跟着关）
- 🟢 锁屏壁纸不变

## 7. i 管家

**路径**：i 管家 → 设置 → 关于 → 个性化设置

- 🔴 应用个性化推荐

## 8. 天气

**路径**：天气 → 设置 → 天气服务

- 🔴 天气相关热点资讯通知
- 🟢 气象预警、异常天气、地震预警

## 9. 营销通知

vivo 推送分类的渠道：`VPushChannel_0`（运营消息）、`VPushChannel_4`（精彩消息）、`VPushChannel_6`（推荐消息）。

- 🔴 支付宝运营、精彩；抖音运营、推荐；云服务推送；使用技巧智能推送建议；Play 特惠；Edge 热门资讯、突发新闻
- ⚠️ 渠道直达参数在 vivo 上无效，打开的是 App 通知总页，要在总页里按渠道名点进去。当前源码的客户端和 `chan-off` 会尝试这样做（Issue #7），0.2.0 安装包尚未包含该处理。
- ⚠️ 渠道页由 `com.vivo.systemuiplugin` 处理，不要强行停止它。

## 10. 广告包和快应用

这台没有挂起任何包，App 内开关够用。

- ⚠️ 快应用 `com.vivo.hybrid`：X300 Ultra（V2547A，Android 17）上系统拒绝挂起（[Issue #7](https://github.com/rddmwmddr/android-ad-cleaner/issues/7)）。在手机上关掉它的通知：设置 → 通知与状态栏 → 应用通知管理 → 快应用 → 关掉「允许通知」。

## vivo 的坑

| 现象 | 对策 |
|---|---|
| 负一屏、全局搜索、主题、i 管家的设置页拉不起来 | 只能从 App 或系统设置里点进去 |
| 列表行和开关各有一个状态 | 以开关本身为准 |
